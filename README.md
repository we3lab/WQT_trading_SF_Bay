# WQT_trading_SF_Bay
A simulation model to calculate credit prices and total regional infrastructure costs for Lower South SF Bay under different market terms and market structures.

The directory contains all jupyter notebooks used to produce figures for this manuscript. The notebooks will import data from the Results directory and produce the required figures. All figures will be saved in the 'Figures' or 'Figures/SI' directory.
